# مصاريفي اليومية

تطبيق عربي بسيط لتسجيل المصاريف اليومية وتقسيمها على أقسام (إيجار، غاز، كهربا، ميه، فواتير، غذاء، أدوية وغيرها)، مع تصدير كل البيانات PDF.

- يتثبت على الموبايل كتطبيق (PWA) ويشتغل من غير نت.
- البيانات بتتحفظ على الجهاز نفسه، ومعاه نسخة احتياطية واستيراد (JSON).

## التثبيت
افتح رابط الموقع على الموبايل في كروم واختار **تثبيت التطبيق**. على الآيفون: سفاري ثم مشاركة ثم **إضافة إلى الشاشة الرئيسية**.
